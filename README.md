# OptimizeCare Medication Adherence Dashboard

## Overview
This project analyzes medication adherence among 1,000 patients using Tableau to identify trends affecting patient compliance and support data-driven healthcare decision-making.

## Tools Used
- Tableau
- Microsoft Excel

## Key Findings
- Average PDC and MPR were 69.24%, indicating moderate medication adherence.
- Only 50.5% of patients met the recommended adherence threshold (PDC ≥ 80%).
- Patients managing multiple chronic conditions demonstrated the lowest adherence rates.
- Higher medication counts were associated with increased therapy gap days, suggesting medication complexity is a key barrier to adherence.
- Age and gender had minimal impact on medication adherence outcomes.
